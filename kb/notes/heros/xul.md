# Xul

**Rôle** : spécialiste de wave — clear de wave monstrueux (Bone Armor, Spectral Scythe), skeletal mages (ult de slow).
**Menaces** : kiting (il est lent) ; les compo qui le kiten sans minions ; % damage.
**À exploiter** : le push de wave (il clear 2 lanes à lui tout seul) ; les zones de choke (le root de Bone Prison, les slows des Skeletal Mages) ; les maps à 3 lanes.
**Pièges** : il est faible en duel ouvert — jouer la macro, pas les teamfights ; son clear nourrit des stacks adverses (Nazeebo, Azmodan) — attention aux match-ups.
**Synergies** : macro (Abathur, Dehaka, Lost Vikings), setups de regroupement, compo qui pousse pendant qu'il split.
