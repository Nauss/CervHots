# Abathur

**Rôle** : enable global — Symbiote sur allié, macro XP permanente, split-push.
**Menaces** : chasseurs de body (Nova, Zeratul, Genji, Valeera) ; globals adverses (Falstad, Dehaka, Brightwing, Ragnaros) qui annulent son split ; burst sur le corps isolé ; CC et engage sur le corps.
**À exploiter** : XP et présence permanente (hat + corps en même temps) ; chaque duel devient un 2v2 ; les maps à 3 lanes ; Toxic Nest pour le siège.
**Pièges** : le corps reste exposé sur une lane — le placer en sécurité avant chaque teamfight ; le hat demande de la micro continue, un hat « oublié » gâche tout ; MULE obligatoire sur Sky Temple / Haunted Mines.
**Synergies** : hypercarries all-in à auto-attaques (Illidan, The Butcher, Varian, Kerrigan, Greymane, Tracer, Zeratul) — Adrenal Overload les rend dévastateurs ; Medivh (portail = escape).
