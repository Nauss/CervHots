# Ana

**Rôle** : support longue portée — heals de précision (rifle), Biotic Grenade (anti-heal ennemi + amplification alliée), Sleep Dart (CC 5s).
**Menaces** : dive sans peel (Genji, Tracer, Zeratul, Valeera) ; les shields qui absorbent ses heals ; alliés mobiles qui rendent ses tirs impossibles ; CC point-and-click (Uther, Malfurion).
**À exploiter** : les compo sustain ennemies (grenade anti-heal pendant leur heal window) ; tanks immobiles qui prennent des dégâts prévisibles ; Nano Boost sur mage burst ou hypercarry AA.
**Pièges** : sans peel elle meurt en 2 s ; Nano Boost ne vaut que sur un bon récepteur (Kael'thas, Gul'dan, Valla, Hanzo, Greymane) — le poser par défaut = gaspillage ; Sleep Dart = un seul cible, CD long.
**Synergies** : hypercarries à Nano (Kael'thas, Gul'dan, Valla, Hanzo, Greymane), tanks immobiles (Johanna, Diablo, Garrosh), Anduin (Leap of Faith = setup Sleep).
