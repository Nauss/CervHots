# Anub'arak

**Rôle** : tank d'engage anti-mage — Burrow Charge, Cocoon (ult de mise à l'écart 8s), scarabées, Impale (stun).
**Menaces** : dégâts automatiques et % damage (Tychus, Valla, Butcher, Malthael) — il est le tank le plus « papier » ; CC chain sur son retour d'engage ; waveclear limité.
**À exploiter** : les compo mages (Cocoon sur le healer = 8 s de 5v4, ou sur le mage) ; engage instantané sur backline ; interrupt à longue portée (Impale, Burrow Charge).
**Pièges** : il est fragile hors engage — jamais premier sans follow-up ; Cocoon mal chronométré (sur un tank déjà bas) = ult perdu ; Impale/Burrow = skillshots esquivables.
**Synergies** : burst d'entrée (Li-Ming, Kael'thas, Jaina), Medivh (portail de sortie), Uther (Divine Shield sur son engage), Johanna / Garrosh (setup pour Impale).
