# Stukov

**Rôle** : support de zone — heals en zone (Lurking Arm = silence de zone), Massive Shove (ult de displacement).
**Menaces** : dive ciblé (il est lent) ; anti-heal (Ana) ; les compo mobiles qui sortent de ses zones.
**À exploiter** : les zones d'objectif (Lurking Arm = silence de zone qui verrouille) ; les compo groupées (ses heals de zone) ; Massive Shove = pick ou disengage.
**Pièges** : ses heals (Healing Pathogen) se propagent avec un délai — les poser avant le dégât, Bio-Kill Switch pour le burst ; Lurking Arm est un channel, interrompre = rien.
**Synergies** : tanks de zone (Johanna, Blaze, Mei), setups de regroupement, compo qui tient le point (Volskaya, Shrines).
