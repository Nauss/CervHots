# Maiev

**Rôle** : assassin de zone — pull (Umbral Bind), Warden's Cage (ult de zone), reset de Fan of Knives (≥ 2 héros touchés), immunité brève (trait Vault of the Wardens).
**Menaces** : kiting (elle doit être collée) ; les compo qui ne se groupent pas (son pull exige plusieurs cibles) ; % damage.
**À exploiter** : les compo groupées (Cage = wipe) ; les backlines collées (pull + burst) ; les zones de choke.
**Pièges** : Warden's Cage sans follow-up ne fait que les enfermer avec vous ; son reset demande de taper au moins 2 héros avec Fan of Knives ; Vault of the Wardens (trait) n'offre qu'une immunité de 0,75 s à timer.
**Synergies** : burst de zone (Kael'thas, Jaina, Gul'dan pendant le Cage), setups (Johanna, E.T.C.), Abathur (hat).
