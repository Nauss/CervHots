# Alarak

**Rôle** : assassin mêlée — burst de combo (Discord Strike = silence), displacement (Telekinesis), Sadisme qui monte.
**Menaces** : kite et portée (Lunara, Valla, Raynor, Li-Ming) ; blinds (Johanna, Cassia, Li Li) ; CC long (Uther, Muradin, Varian) ; Cleanse qui casse son combo ; Medivh (Force of Will, Poly Bomb) ; Deathwing (unstoppable = ignore son combo).
**À exploiter** : tanks immobiles (Stitches, Arthas) qu'il punit ; les compo qui viennent à lui (counter-engage) ; les zones étroites ; combo sur tanks avec follow-up = kill garanti.
**Pièges** : combo raté = il est en mêlée sans rien ; ses stacks de Sadisme se perdent en partie à la mort — pas de duel inutile ; waveclear nul — dépend de l'équipe.
**Synergies** : E.T.C. (Mosh + combo), Garrosh (throw = combo garanti), Johanna (pull = combo garanti), Medivh (portail + protection), Jaina / Raynor (waveclear + follow-up burst).
