# Zagara

**Rôle** : spécialiste de push et de vision — Nydus (réseau de tunnels), broods, Maw (ult d'isolement de zone).
**Menaces** : dive rapide (elle est squishy) ; les compo qui clear ses broods ; les chasseurs de Nydus.
**À exploiter** : la vision permanente (creep = vision de la map) ; le split multi-lane (Nydus) ; les zones de choke (Maw = isolation).
**Pièges** : son creep se clear (les adversaires attentifs le font) ; Maw rend les cibles intouchables 4 s (elles ne peuvent ni agir ni être attaquées) — le burst se joue à la sortie, et un Maw mal timé sauve l'adversaire.
**Synergies** : macro (Abathur, Dehaka), setups pour Maw (Johanna, E.T.C.), compo qui pousse (Sgt. Hammer, Azmodan).
