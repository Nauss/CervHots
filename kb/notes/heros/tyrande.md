# Tyrande

**Rôle** : support/assassin hybride — mark (Hunter's Mark = + dégâts), heal, stun (Lunar Flare), Shadowstalk (invisibilité d'équipe).
**Menaces** : dive ciblé (elle est squishy) ; les compo qui la focus (son heal est mono-cible et plafonné) ; kiting.
**À exploiter** : le mark = focus d'équipe sur une cible ; Shadowstalk = engage surprise ou disengage ; son stun de zone.
**Pièges** : son heal (Light of Elune) est mono-cible à charges limitées — depuis sa refonte elle tient la place de solo heal ; Lunar Flare se rate, la viser sur les cibles CC-ées.
**Synergies** : bursts qui suivent son mark (Greymane, Li-Ming, Hanzo), vision combinée (Hanzo, Medivh), Nova/Abathur (mark + snipe).
