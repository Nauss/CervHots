# Anduin

**Rôle** : support — sauvegarde (Leap of Faith = traction d'un allié + Unstoppable), counter-engage (Lightbomb), heals fiables (Lightwell, Renew).
**Menaces** : dive coordonné (ses heals sont réactifs, pas préventifs) ; silence/burst pur (Brightwing, Uther, Valeera) ; CC chain sur lui.
**À exploiter** : sauver l'allié attrapé par un Garrosh/Stitches/Diablo (Leap annule leur pick) ; Lightbomb en counter-engage sur un engage adverse ; setup pour mages (Lightbomb + follow-up burst) ; Glyph of Faith (L16) = double Leap.
**Pièges** : Leap of Faith a un long CD — ne le gaspiller que sur la vraie menace ; Lightbomb sur un allié immobile est souvent mieux que sur le tank qui charge ; Inner Focus build = survie perso, moins de heal équipe.
**Synergies** : mages immobiles attrapables (Kael'thas, Gul'dan, Chromie), tanks qui engagent (Garrosh, Diablo, Anub'arak), Genji (Lightbomb -> Swift Strike reset), Johanna / Blaze (CC fiable pour Chastise).
